# Standard Minecraft display names

Small item/block/entity/enchantment name tables are extracted from checksum-verified Minecraft language assets distributed by Mojang, with source hashes in `vanilla-names/sources.json`. Names remain owned by their respective authors; these extracts are provided for interoperability and are not plugin branding or an endorsement. No textures, sounds, client archive or executable game files are bundled.

Turkish and eight other language tables use Minecraft 26.2 assets, including older supported item keys. English uses the existing Paper 26.2 server's default table. Names are resolved on the server using the player's selected plugin language, so changing plugin language also changes picker labels even when the client language differs. Custom named items preserve their metadata. Command identifiers, database values and material filters remain technical IDs.

Paper Material translation API: https://jd.papermc.io/paper/1.20.6/org/bukkit/Material.html#translationKey()
Official asset metadata: https://piston-meta.mojang.com/mc/game/version_manifest_v2.json
